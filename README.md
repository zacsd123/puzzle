# 퍼즐 파티 🧩

사진 한 장을 올리면 퍼즐 조각으로 잘라, 여러 사람이 **실시간으로 함께** 맞출 수 있는 웹 게임입니다.

- 메인 화면에서 **방 만들기 / 방 참여하기** 선택
- 입장할 때는 **이름만** 입력 (초대 링크로 바로 들어와도 이름만 물어봄)
- 모든 참가자의 **마우스 커서가 이름표와 함께 실시간 공유**되고, 누가 어떤 조각을 들고 있는지 색 테두리로 표시
- **조각끼리 이어 붙이기**: 이웃한 조각을 서로 맞는 위치 근처에 놓으면 찰칵 붙어서 한 덩어리가 되고, 이후에는 덩어리째로 함께 움직입니다.
- 조각이나 덩어리를 퍼즐판의 정답 자리 근처에 놓으면 판에 고정됩니다. 판에 고정된 덩어리는 더 이상 움직일 수 없어요.
- 모든 조각이 하나로 이어지면 퍼즐 완성! 진행도는 "남은 덩어리 수"로 표시되고, 참가자별로 **연결 횟수**(붙인 횟수)를 집계합니다.
- 다른 사람이 들고 있는 덩어리는 잡을 수 없고, 그 덩어리와는 붙지도 않습니다. (놓는 순간 붙을 수 있으면 그때 붙음)
- 줌(휠) / 화면 이동(빈 곳 드래그) / 원본 힌트 보기

## 기술

React + TypeScript (Vite) 화면, Node + TypeScript 서버(`ws` WebSocket). 서버 하나가 화면과 WebSocket을 모두 서비스합니다.

```
src/      React 화면 (페이지, 캔버스 렌더러, 접속/상태 관리)
server/   HTTP API(이미지 업로드) + WebSocket 게임 서버
shared/   서버·화면이 같이 쓰는 메시지 타입
```

## 실행

처음 한 번:

```bash
npm install
```

**개발 (코드 수정이 바로 반영됨)** — 화면 `http://localhost:5199`, 서버 `3001`

```bash
npm run dev
```

**실제 운영 (맥미니/데스크탑에서 켜두는 방식)** — 한 포트(기본 `3001`)로 모두 제공

```bash
npm run build
npm start
```

서버를 켜면 접속 주소가 출력됩니다. 같은 와이파이의 다른 기기에서는 출력된 `http://192.168.x.x:3001` 로 접속하면 됩니다.

포트는 `PUZZLE_PORT=8080 npm start` 처럼 바꿀 수 있습니다.

## 인터넷의 친구와 함께 하려면

같은 와이파이 밖의 사람이 접속하려면 내 컴퓨터를 인터넷에 노출해야 합니다. 쉬운 순서대로:

1. **Cloudflare Tunnel** (`cloudflared tunnel --url http://localhost:3001`) — 공유기 설정 없이 임시 `https://...` 주소를 줍니다.
2. **Tailscale** — 친구들도 Tailscale에 초대하면 사설망처럼 접속할 수 있습니다.
3. **공유기 포트포워딩** — 3001 포트를 이 컴퓨터로 열어주고 공인 IP로 접속. (HTTPS 없이 노출되니 주의)

> 방은 서버 메모리에만 저장됩니다. 서버를 재시작하면 방과 진행 상황이 사라지고, 아무도 없는 방은 6시간 뒤 자동 삭제됩니다.

## 제한

- 사진은 업로드 전에 브라우저에서 긴 변 1600px 이하 JPEG로 줄여서 올립니다 (서버 최대 8MB).
- 조각은 최대 400개, 방당 최대 20명, 동시에 최대 100개 방.
- 붙는 거리 기준은 조각 짧은 변의 30%입니다. (`shared/protocol.ts`의 `SNAP_RATIO`로 조절)
